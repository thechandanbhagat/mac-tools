# Clipboard History
Mode: Operate. Extend the existing native Mac Tools visual system.

## Direction contract
THESIS: Let the user explicitly remember recent copies for this session, retrieve a selected item, or save it to Key Vault for future use.
OWN-WORLD: Inherit the searchable split-pane pattern, native text/image preview, semantic surfaces, shared help, and fixed footer.
STORY: Start or opt into capture on launch in Settings; copy text or an image; search or select history; preview; Copy or Save to Key Vault with a name and optional Sensitive flag; pause, remove, or clear as needed.
FIRST VIEWPORT: Title/help, searchable history and preview, visible Recording / Paused status, Start / Pause, and Copy / Save to Key Vault disabled until selection.
FORM: A focused session list with an explicit Save to Key Vault action, without automatic onboarding panels.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Constraints
Recording starts off by default; Settings offers explicit capture-on-launch opt-in that applies on the next launch. Capture begins with the next copy, never importing the existing pasteboard. Start and Pause control the current session without changing the launch preference. Store only session memory with count/byte limits; clear on quit. The Settings history limit offers 25, 50, 100 (default), 200, or 500 items within a 20 MiB cap. Lowering the limit immediately removes older entries while retaining the newest and preserving paused/running state. Pause stops collection; Clear and individual removal affect history without clearing the system clipboard. Copy writes the selected content but never pastes into another app.

Save to Key Vault explicitly stores the selected item separately for future launches through a native sheet with a visible, accessible Name label and Sensitive control. Disable Save while the vault is busy and retain edits when a submission cannot start. Saved vault payloads use schema version 2, which earlier version-1 builds refuse rather than dropping sensitivity metadata. Session-history clearing, removal, limit changes, and quit never delete saved vault items. Saving or marking an item sensitive removes matching values from current session history. Subsequent capture skips matches against sensitive vault entries already loaded in memory; it does not import or erase the system clipboard, and cannot exclude unloaded or unmarked values by that comparison. Show save success or failure; do not persist captured history automatically. Demo saves sample entries only in memory without accessing the real vault or Keychain.

Support text and images only. Respect recognized password-manager, concealed, transient, and autogenerated markers when supplied, and explain that unmarked sensitive content can still be captured. Keep limits and supported types in accessible help. Demo history is labeled and cannot capture or write the real clipboard. Preserve clear Recording / Paused status and actual empty/search states.
