# Clipboard History
Mode: Operate. Extend the existing native Mac Tools visual system.

## Direction contract
THESIS: Let the user explicitly remember recent copies for this session and retrieve a selected item.
OWN-WORLD: Inherit the searchable split-pane pattern, native text/image preview, semantic surfaces, shared help, and fixed footer.
STORY: Start; copy text or an image; search or select history; preview; Copy; pause, remove, or clear as needed.
FIRST VIEWPORT: Title/help, searchable history and preview, visible Paused status, Start, and disabled Copy until selection.
FORM: A focused session list without automatic onboarding panels or persistent storage controls.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Constraints
Recording starts off on every launch and begins with the next copy, never importing the existing pasteboard. Store only session memory with count/byte limits; clear on quit. Pause stops collection; Clear and individual removal affect history without clearing the system clipboard. Copy writes the selected content but never pastes into another app.

Support text and images only. Respect recognized password-manager, concealed, transient, and autogenerated markers when supplied, and explain that unmarked sensitive content can still be captured. Keep limits and supported types in accessible help. Demo history is labeled and cannot capture or write the real clipboard. Preserve clear Recording / Paused status and actual empty/search states.
