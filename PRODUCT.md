# Product

<!-- impeccable:product-schema 1 -->

## Platform
macOS (native desktop)

## Stack
The user confirmed a native SwiftUI Mac app and asked to build it now. Swift Package Manager, Swift 6, macOS 14+. Foundation, AppKit, CryptoKit, Security, Darwin/IOKit, ImageIO, CoreGraphics, and PDFKit provide local capabilities. No external dependencies.

## Product Purpose
A collection of useful tools for Mac: Cleaner, Storage Map, Large & Old Files, Developer Cleaner, Duplicate Finder, Empty & Broken, Batch Renamer, File Converter, Metadata, Checksums, Clipboard History, Key Vault, Uninstaller, Startup Manager, Active Ports, and System Monitor. These sixteen tools share the existing native interface and concise interaction language, organized into Storage, Files, and System sidebar sections, with cross-tool context menu handoffs, drag-and-drop support, and inline Quick Look previews.

## Capabilities and Constraints
Cleaner scans local storage, explains cleanup candidates, reviews individual files, and moves explicitly selected files to Trash. No automatic deletion or permanent removal. Permissions, partial scans, cancellation, and failed operations remain visible.

Large & Old Files scans a chosen folder for files of at least 10 MB, with filters for minimum size (10 MB+, 50 MB+, 250 MB+, 1 GB+), modification age, and file kind, moving explicitly selected files to Trash after confirmation and snapshot revalidation.

Developer Cleaner scans a chosen projects folder for rebuildable build outputs and dependency directories (`node_modules`, `.build`, `DerivedData`, `Pods`, `target`, `.gradle`, `.next`, `.venv`, `__pycache__`), measures their allocated size, and moves explicitly selected directories to Trash after confirmation and snapshot revalidation.

Empty & Broken scans a chosen folder for empty directories and broken symbolic links, revalidating that folders are still empty and symlinks are still broken before moving confirmed selections to Trash.

Metadata inspects local images, PDFs, and files for EXIF, GPS location coordinates, TIFF/IPTC properties, PDF document attributes, and macOS extended attributes (`com.apple.quarantine`, `kMDItemWhereFroms`), and either exports clean `-clean` copies without overwriting originals or strips extended attributes in place after confirmation.

Checksums computes SHA-256, SHA-512, SHA-1, and MD5 digests for local regular files using streaming descriptor reads, compares them against an expected checksum string, and copies digests to the clipboard without uploading files.

Active Ports lists local TCP listening sockets and UDP endpoints using `/usr/sbin/lsof`, showing port, protocol, address, PID, process name, and executable path, with confirmed Quit (`SIGTERM`) and Force Quit (`SIGKILL`) for user-owned processes after verifying executable path identity.

Storage Map scans a chosen folder, shows a proportional map and size-sorted contents, and automatically scans each folder opened through drilldown or breadcrumbs. Manual refresh targets the current folder. Each scan has independent limits and hard-link attribution; navigation preserves the breadcrumb location. Ordinary refresh cancellation or failure retains that folder’s prior snapshot; changing folders or options clears incompatible results. Scans read metadata only. A separate context-menu action can move an ordinary file or folder to macOS Trash after confirmation. Folder confirmation includes all contents, including hidden items. A fresh complete subtree check supplies the folder size and rejects unsupported or inaccessible contents. Packages, the displayed root, and grouped map regions remain excluded. The app rechecks the item and its path, rejects detected changes, and refreshes the current folder after success.

Uninstaller finds user-installed apps in /Applications and ~/Applications. Selecting an app inspects its size and exact bundle-identifier matches in supported user Library locations. Related items are optional and initially unchecked. A review lists the app and explicitly selected related files before confirmation. Running apps must be quit; system locations, Mac Tools itself, shared containers, privileged helpers, and fuzzy name matches are excluded. Incomplete items cannot be removed. Revalidation precedes Trash, and related items move only after the app succeeds. This scoped tool does not promise exhaustive removal of everything an installer may add.

Duplicate Finder compares ordinary local files using size and SHA-256 content hashes. Selection starts empty and must leave one copy in each affected group. Review names selected files before Trash, and the affected group is rechecked before removal. Scans skip links, Finder aliases, resource-fork files, hidden items, packages, cloud locations, other volumes, and duplicate hard-link identities, with limits and issues visible.

Startup Manager reviews the user and all-user LaunchAgents directories and the all-user LaunchDaemons directory. Search and scope filters expose configured programs and triggers without claiming current running or enabled state. Modern login/background registration is not exhaustively represented by those files. Management uses the native Login Items settings; Mac Tools does not modify launch configurations or unload services.

System Monitor samples CPU, active memory, home-volume capacity, physical disk I/O, and active Ethernet/Wi-Fi/cellular network counters locally. Sampling runs every two seconds only while the tool is visible in the main window or both the menu-bar item and its CPU display are enabled. Rates use differences between compatible readings; unavailable values remain explicit. Sampling stops on quit and makes no network requests.

Batch Renamer supports find-and-replace, prefixes, suffixes, numbering, and the current date, preserving extensions by default. Preview and confirmation precede changes, files stay in their folders, and changed files or name collisions are refused. The latest successful batch has a session-local, reviewed Undo. Applying a batch finishes or attempts rollback before normal application termination.

Clipboard History is off at launch by default. Users can start it for the current session or enable capture on launch in Settings. Capture collects only new copies and never imports the existing clipboard. Text and images stay in bounded session memory, with search, preview, Copy, Pause, individual removal, and Clear. Save to Key Vault explicitly keeps a selected item for future use through a sheet offering Name and Sensitive. Saving or marking an item sensitive removes matching entries from current history; capture also skips values matching sensitive vault entries already loaded in memory. Copy never pastes into another app. Recognized sensitive/transient pasteboard markers are skipped when provided; unmarked or not-yet-loaded sensitive data can still be captured. Session history is not saved to disk and quit clears it; separately saved vault items remain.

Key Vault is a separate Files page for explicitly saved clipboard text and images. Users search, preview, copy, edit Name/Sensitive in Details, and confirm deletion of saved items. Sensitive values stay hidden in list rows, the quick-paste picker, deletion confirmation, accessibility labels, and search; their visible names remain searchable. Reveal explicitly shows the selected preview, and Hide, selection/tool changes, app deactivation, or 30 seconds conceal it again. This is visual privacy without authentication: Copy and Paste remain explicit actions and do not require Reveal, Touch ID, or a password. Sensitive copies use a concealed clipboard marker and clear after 30 seconds, or on quit, only if Mac Tools still owns the unchanged copy. Other apps may ignore markers or retain previously read content.

The vault persists up to 500 items and 20 MiB in an AES-GCM encrypted local file at `~/Library/Application Support/MacTools/KeyVault/vault.enc`, using a key stored in macOS Keychain. Names and sensitivity flags are encrypted with the content; legacy entries default to nonsensitive. Reads accept payload versions 1 and 2; saves write version 2 so earlier builds refuse the file instead of silently losing sensitivity metadata. Names allow up to 200 characters and 800 UTF-8 bytes. Full vaults refuse new items without evicting saved entries. Keychain, decryption, and storage failures stay visible; there is no plaintext fallback. Clearing clipboard history or quitting does not delete saved vault entries. Demo mode offers a fictional sensitive item and saves/deletes sample vault items only in memory, without accessing disk, Keychain, or the host clipboard.

Control–Option–V opens a temporary Key Vault picker near the pointer while Mac Tools is running. Users search and click an item, or use arrow keys and Return, to paste into the originally focused text field. Sensitive rows expose only their names and remain searchable by name, without revealing their values. Escape, an outside click, or the shortcut again closes it. The app captures only destination identity, verifies Accessibility access and unchanged app/field focus, then copies the chosen item and dispatches native Command-V without submitting. Sensitive copies use the same concealed-marker and conditional clearing behavior as the main vault Copy action. Unsupported destinations and permission failures remain visible with a manual Copy alternative; actual insertion depends on the receiving editor. Images require an image-capable destination. The shortcut is enabled by default, can be disabled in Settings, and keeps the app running after its main window closes. Accessibility permission is enabled manually in System Settings; there is no automatic grant. Demo can preview the picker from Tools but never registers the global shortcut or pastes into another app.

Settings is a dedicated page reached from the sidebar, the Mac Tools menu with Command-comma, or the menu-bar extra. Preferences save locally and automatically. Theme defaults to System; the opening tool defaults to Cleaner; the menu-bar item, CPU display, and clipboard capture on launch default to off; Key Vault quick paste defaults to on. Existing enabled system-monitor menu preferences migrate to an enabled menu-bar item with CPU display. Theme, menu-bar visibility, quick paste, and the clipboard history limit apply immediately; the opening tool and clipboard launch preference apply on the next launch. History keeps up to 100 items by default, configurable to 25, 50, 100, 200, or 500 within the existing 20 MiB memory limit. Lowering the limit removes older entries. Start and Pause never change the launch preference, and demo mode cannot capture or write the system clipboard.

Launch at login registers or unregisters Mac Tools through the native macOS Login Items service. System registration is the source of truth, including external changes and pending approval; it is off until enabled unless already registered. Errors and approval requirements remain visible with an action opening Login Items settings. A login launch stays in the background with the menu-bar item enabled and no main window or Dock icon. Opening Mac Tools directly or choosing a main-window action from its menu shows the app normally. The initial tool is selected without opening its window during quiet startup. Demo mode previews registration in memory without changing the system registration; an explicit background launch can preview the quiet startup behavior.

The optional Mac Tools menu-bar item provides access to the main window, Key Vault, Clipboard History, System Monitor, Settings, Quit, recent clipboard items, and capture controls. It uses the app's SF Symbol unless Show CPU usage is enabled; CPU mode adds live readings and Refresh. CPU display defaults to off and preserves an explicit user choice. Hiding the item preserves the CPU preference. Enabling the menu-bar item keeps Mac Tools running after its main window closes, independently of quick paste. Login and explicit background launches turn on the menu-bar preference to provide an opening and quitting route.

File Converter exports images as JPEG/PNG/TIFF with optional resizing, combines PDFs in the chosen order, and rasterizes PDFs at selected resolution and quality. PDF compression visibly warns that searchable text, links, forms, and annotations are lost in the exported copy; smaller size is not guaranteed. Originals and existing exports are preserved. Unsupported inputs, limits, cancellation, and per-file failures remain visible.

Cleanup tools use macOS Trash only after explicit confirmation. They never empty Trash or fall back to permanent deletion. No tool requests administrator privileges. Demo mode labels sample data, disables Trash, renaming, clipboard capture and clipboard writes, confines converter exports to its disposable sample folder, keeps Key Vault changes in memory, and never changes host login registration.

## Product Principles
- Show real disk data and a clear scan scope.
- Keep the user in control of every cleanup.
- Use familiar macOS interactions and accessible system controls.
- Keep the interface clean and simple: retain concise necessary labels; omit slogans, redundant explanations, and repeated reassurance.
- Put secondary explanations in contextual native help, using `questionmark.circle` where useful with hover and accessible keyboard/click access. Keep errors, partial results, and destructive consequences visible when needed.
